# 04. Сетевой протокол клиента «Третий Мир» (J2ME, 2D, версия 3.0.1)

Восстановлено декомпиляцией оригинального клиента (`Third_World_War_of_Kings_2D.jar`,
MIDlet `com.fenix.main.Main`, Fenix-Soft, сборка 30.11.2009 / 29.01.2010, строка версии `28092009x3`)
и проверено запуском **настоящего клиента** в эмуляторе против нашего сервера (`server/`,
`tools/client-harness/`).

Имена классов клиента обфусцированы — ниже в скобках указано, где что лежит, чтобы можно было
перепроверить по декомпиляции (`java -jar cfr.jar client.jar --outputdir src`).

---

## 1. Транспорт

| Параметр | Значение | Где в клиенте |
|---|---|---|
| Соединение | TCP `socket://mmog1.com:2500` | `com.fenix.main.h` (host `c`, port `b`), `com.fenix.main.d` |
| Кто начинает | **сервер** (шлёт SNAC 1,0 после подключения) | `g.a(d)` |
| Кодировка текста | cp1251 (своя таблица: А–я = 0xC0–0xFF, Ё/ё = 0xA8/0xB8, укр. буквы) | `g.a(String)`, `g.b(byte[],…)` |
| Порядок байт | big-endian | `g.b`, `g.c` |
| Буфер приёма | кольцевой 256 байт (большие пакеты читаются кусками, но работают) | `com.fenix.main.d` |

Сменить адрес без пересборки: `tools/patch_client.py` (переписывает строку `mmog1.com` в пуле констант
и `sipush 2500`).

## 2. Кадры

### FLAP (как в ICQ/OSCAR)
```
+------+---------+----------+----------+------------------+
| 0x2A | channel |  seq u16 |  len u16 | payload[len]     |
+------+---------+----------+----------+------------------+
```
- **channel 1** — системный (рукопожатие, вход, регистрация). Обрабатывает `g.a(d)`.
- **channel 2** — игровой. Обрабатывает `k.a(d)`.
- **channel 4** — клиент закрывает сессию (пустой payload).
- **seq**: клиент всегда шлёт `1`. Младший байт seq во **входящем** пакете канала 2 клиент использует как
  «ответ пришёл» — гасит индикатор ожидания (крутящиеся точки / часы). **Сервер должен слать seq ≥ 1.**

### SNAC (payload каналов 1 и 2)
```
| group u16 | sub u16 | data ... |
```
### TLV (почти всё содержимое data)
```
| type u16 | len u16 | value[len] |
```

Далее SNAC записывается как `(group,sub)`; `C→S` — от клиента, `S→C` — от сервера.

## 3. Рукопожатие, вход, регистрация (канал 1)

```
S→C  ch1 (1,0)                                  «привет»
C→S  ch1 (1,1)  u16 width, u16 height           размер экрана (если логотип #10 не закэширован)
C→S  ch1 (4,12) u32 savedUserId                 если в RMS сохранён id прошлого входа
C→S  ch1 (1,0)  "28092009x3"                    версия клиента (сырые байты)
S→C  ch1 (4,0)                                  показать заставку и форму входа
C→S  ch1 (4,5)  TLV1 login, TLV2 password       ВНИМАНИЕ: клиент приводит оба к нижнему регистру
S→C  ch1 (4,5)  u32 userId                      вход успешен → клиент переходит в игровой режим
      (ошибка входа: S→C ch2 (12,0) TLV13 — всплывающее сообщение, см. §6)
C→S  ch2 (10,0)                                 «я в игре» (первый пакет канала 2)
S→C  ch2 (10,0)                                 показать игровой экран
```
Что ещё умеет обработчик `g.a(d)`: `(4,6)` — перейти на пустой экран (`y`), `(4,0)` — снова форма входа.

**Регистрация** — форма целиком нарисована клиентом (`q`, кнопка с кодом 10). Кнопка «Продолжить» шлёт:
```
C→S  ch1 (4,7)  TLV1 имя, TLV2 пароль, TLV3 e-mail, TLV4 раса ("0" Люди, "1" Эльфы, "2" Гномы),
                TLV5 "", TLV6 чекбокс «Принимаю», TLV7 контрольный вопрос, TLV8 ответ    (все — строки)
```
Ссылки «?» в форме шлют `ch2 (4,8) TLV0` (подсказка). Ответ сервера — на усмотрение (наш сервер: `(4,0)` +
сообщение).

## 4. Игровой экран: Замок / Земли / Мир

Клиент хранит текущий вид `k.h`: 0 — Замок (сетка 7×7), 1 — Земли (15×15), 2 — Мир (окно 7×7).
Клавиша `*` циклически переключает вид: Замок → `(10,4) TLV1` → Земли → `(10,8)` → Мир → `(10,4) TLV0` → Замок.

### 4.1 Сетка зданий `S→C (10,1)`
| TLV | Значение |
|---|---|
| 6 | u8: 1 — рисовать забор/стены вокруг замка |
| 8 | u8: вид (0 замок, 1 земли) |
| 7 | u8: 1 — переключить клиент на этот вид |
| 9 | 49 или 225 байт (**signed**): id здания в клетке, `-1` пусто, `-2` идёт стройка. Порядок: строка за строкой, `index = y*size + x` |
| 10 | записи прогресса строек по 11 байт: `u8 цвет(0/1/2), u16 id, u16 x, u16 y, u16 всего_сек, u16 прошло_сек` — клиент рисует полоску и сам увеличивает «прошло» раз в секунду |

Картинка здания = изображение `100 + id` (см. §7). Рельеф Земель (лес, валуны, горы, вода, берега)
**зашит в клиенте** (массивы `k.j/k.k/k.l`) — сервер должен знать ту же карту (см. `server/src/game.js`).

### 4.2 Действия на сетке `C→S`
| Клавиша 5 на клетке… | Пакет | Ответ сервера (наш) |
|---|---|---|
| пустая (-1) | `(10,5)` raw `u16 x, u16 y` | окно списка зданий (группа 12) |
| здание (≥0) | `(10,7)` raw `u16 index` | окно здания |
| стройка (-2) | `(10,3)` raw `u16 index` | сообщение «осталось …» |
| `0` | `(10,35)` | — |
| `#` | — (локально) | окно ресурсов из последнего `(10,6)` |

Ответ на стройку `S→C (10,2)`: TLV3 u16, TLV4 u16 index, **TLV5 u16 статус** (0 — ок, клиент ставит в клетку -2;
1 — занято; 2 — нет ресурсов), TLV10 прогресс (как в 10,1).

### 4.3 Ресурсы `S→C (10,6)`
Порядок ресурсов в клиенте: **дерево, камень, железо, еда, люди**.
| TLV | Значение |
|---|---|
| 10 | 5 × u32 — текущие запасы |
| 11 | 5 × u16 — добыча в час (клиент сам «дотикивает» между обновлениями; людей делит на 86400) |
| 12 | 5 × u32 — вместимость |

### 4.4 Нижняя строка состояния `S→C (10,10)`
TLV0 u16 N; TLV1…TLVN — по 4 × u16: `иконка_если_значение>0, иконка_если_0, значение, показывать_число(1/0)`.

### 4.5 Часовой пояс `S→C (10,11)`
TLV0 — строка вида `GMT+03:00` (часы в верхней рамке).

### 4.6 Карта мира `S→C (10,8)`
| TLV | Значение |
|---|---|
| 16 | u16 x0, u16 y0 — левый верхний угол окна 7×7 |
| 17 | объект: `u32 id владельца, u16 x, u16 y, u16 тип (0 — замок: окно рисует клиент, иначе — запрос 10,36), u16 картинка, u16 рейтинг, u8 len1, u8 len2, u8 len3, name, owner, alliance, race` |
| 18 | u16 cx, u16 cy — центр (для подписи «X: Y:» и прокрутки) |

Картинка объекта = `601 + N` (0 трава, 1 камни, 8 камни2, 9 вода, 10 замок — клиент сам выбирает маленький/обычный/большой
по рейтингу <300/<1000/≥1000, 24 старый замок, 25 дикари, 26 лесорубы, 27 рудник троллей).
Строки name/owner/alliance — в формате `Префикс:значение` (клиент берёт часть после `:`).

Прокрутка за край окна: `C→S (10,18)` raw `u16 cx, u16 cy` (новый центр). Клик по не-замку: `(10,36)` raw `u16 x, u16 y`.
Окно чужого замка (рисует клиент) даёт кнопки `(10,20)` TLV1/2/3 = u32 id игрока (сообщение/торговля/войска) и
ссылку на профиль `(11,15) TLV10 u32 id`.

## 5. Главное меню (правая софт-клавиша, класс `b`)

| Пункт | Пакет |
|---|---|
| Bug! | `(11,16) TLV0` |
| Кабинет | `(11,18) TLV0` |
| Почта ▸ Написать / Входящие / Исходящие / Отчёты | локальная форма / `(11,6) TLV0 u16 0/1/2` |
| Локации ▸ Замок / Земли / Мир | `(10,4) TLV0` / `(10,4) TLV1` / `(10,8)` |
| Рейтинг | `(11,17) TLV0` |
| Справка | `(10,22) TLV0` |
| Бонус | `(10,24) TLV0` |
| Выход | ch4 + закрытие сокета |

### Почта
- Список `S→C (11,6)`: TLV4 = `u16 показано, u16 всего, u16 страница`; TLV5 на письмо =
  `u32 id, u16 len+от кого, u16 len+тема, u16 len+дата, u16 прочитано(0 — значок «новое»)`
  (для папки «Отчёты» поля «от кого» нет).
- Открыть письмо — ссылка `{u11|6|1|id|тема}` → `C→S (11,6) TLV1 u32 id` → `S→C (11,5)` TLV1 от, TLV2 тема, TLV3 текст,
  TLV4 дата, TLV6 u32 id отправителя. Кнопки окна письма: `(11,6)` TLV2 удалить, TLV6 ответить, TLV7 переслать, TLV10 переписка.
- Форма «Написать» (локальная или по `S→C (11,7) TLV1 = u8 len+кому, u8 len+тема`) → `C→S (11,5)` TLV1 кому, TLV3 тема, TLV4 текст.
- Уведомление `S→C (11,4)`: TLV1 — «новое письмо», TLV3 строка — всплывающее сообщение.

## 6. Окна, которые строит сервер — `S→C (12, *)`

Главная находка: почти весь интерфейс (здания, списки, диалоги) **описывается сервером**. Клиент
(`k.l()`, «windowConstructParser») собирает окно из строк; элементы копятся, пока не придёт TLV5.
`ga`/`va` — выравнивание элемента: 0 лево/верх, 1 центр, 2 право/низ.

| TLV | Элемент | Формат value |
|---|---|---|
| 12 | заголовок / разделитель (сам закрывает строку) | `u8 стиль` (0 — заголовок, далее текст; 1 — линия) |
| 5 | конец строки | — |
| 7 | текст (с разметкой) | `u8 ga, u8 va, u16 id_встроенной_строки, текст` |
| 6 | метка / ссылка | `u8 ga, u8 va, u16 group` (0 — просто текст), `[u16 sub, u16 tlv]`, текст |
| 9 | поле ввода | `u8 ga, u8 va, u8 тип (5 текст, 2 пароль, 4 текст, 1 число), u16 id, u8 макс_длина, [значение]` |
| 8 | многострочное поле | `u8 ga, u8 va, u8 (0 — редактируемое), u16 id, [текст]` |
| 15 | выпадающий список | `u8 va, u8 ga` (порядок обратный!), `u16 id, u8 N, N×(u8 len+строка), [N×u32 значения]` |
| 18 | чекбокс | `u8 ga, u8 va, u16 id, текст` |
| 11 | картинка | `u8 ga, u8 va, u16 id_картинки` |
| 10 | кнопка | `u8 ga, u8 va, u8 режим, …, текст` — см. ниже |
| 16 | навигация | `u16`: 0 — очистить стек окон, 1 — запомнить текущее окно для «Назад», 2 — ничего, 10 — корень |
| 13 | **всплывающее сообщение** (обрабатывается сразу) | `u8 куда (0 текущий экран, 1 карта замка, 2 меню), текст` |
| 22 | **бегущая строка** сверху (сразу) | `u8 повторы, u32 цвет 0xRRGGBB, текст` |
| 20 | обновить значения полей предыдущего окна | `u16 N, N×u16 id, N×(u8 len+строка)` |

**Режимы кнопки (TLV 10):**
| Режим | Формат после `u8 режим` | Что шлёт клиент |
|---|---|---|
| 0 | `u16 group, u16 sub, u16 -, u8 N, N×u16 id_полей` | `(group,sub)`, значения полей: TLV(type = id поля, value = строка) |
| 1 | `u16 group, u16 sub, u16 tlv` | `(group,sub)` + пустой TLV(tlv) |
| 2 | `u16 group, u16 sub, u16 tlv, u32 param` | `(group,sub)` + TLV(tlv, u32 param) |
| 3 | `u16 действие` | ничего; локально: 0 — закрыть/назад, 27 — переподключиться |

**Разметка текста (TLV 7):**
- `{iN}` — вставить картинку N (0 дерево, 1 камень, 2 железо, 3 еда, 4 люди, 5 часы, 100+ здания, 200+ юниты…);
- `{uG|S|T|P|текст}` — ссылка: по нажатию `(G,S)` + `TLV(T, u32 P)`; `{uG|S|T|текст}` — без параметра.

## 10. Что ещё не разобрано

- Тренировка войск, армии, бой, альянсы, экспедиции в этой версии клиента почти не имеют своего кода — они
  строятся окнами группы 12 и ссылками `{u…}`. Значит, их формат мы задаём сами на сервере, а старый клиент будет их
  показывать без изменений.
- Исключение — экран торговли/аукциона (класс `o`): кнопки шлют `(10,15) TLV0` (торговля), `(10,11) TLV1/TLV2`
  (лоты аукциона), таблица «Ресурс / Добыча / Значение». Формат ответов ещё предстоит восстановить.
- Сообщения `(10,20)` из окна замка на карте, `(11,26)` (поиск по координатам «Перейти X/Y»), `(11,9)` (альянс).
