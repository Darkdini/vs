# 05. Запуск и проверка игры

Сервер сам отдаёт игру в браузер телефона — ставить ничего не нужно.

```bash
cd ~ && rm -rf vs && unzip -q ~/storage/downloads/vs-*.zip && mv vs-* vs   # код из «Загрузок»
cd ~/vs/server && npm start
```

Откройте в Chrome на телефоне **http://localhost:8080**. Меню Chrome → «Добавить на главный экран» запускает игру
как приложение, во весь экран. Графика — из оригинальных клиентов «Третий Мир» (`web/gfx`, `web/gfx3d`).

**Админ:** логин `admin`, пароль `admin`.

| Экран | Что там |
|---|---|
| Вход / регистрация | логин, пароль, раса (Люди, Эльфы, Гномы) |
| Замок | изометрическая карта 7×7: палец — двигать, щипок — масштаб, нажатие на клетку — здание |
| Здание (шторка снизу) | уровень, что даёт, рейтинг, цена и время следующего уровня, **таблица всех уровней** (ресурсы, время, добыча, рейтинг) |
| Земли | 15×15: лес — Дровосек, валуны — Каменьщик, горы — Рудник, трава — Огород/Хибара, вода — Рыболовная заводь |
| Мир | замки игроков и объекты карты, профиль, письмо владельцу |
| Рейтинг | таблица игроков; рейтинг замка — до 2300 при полной застройке (замок до 1300 + земли до 1000), рейтинг игрока — сумма его замков |
| Ещё | профиль, почта, справочник зданий, войска рас, формулы, сообщение об ошибке, выход |

Отрисовка повторяет оригинальный J2ME-клиент (декомпиляция класса `s`): земля и поле `grass1` на 5 клеток вокруг,
ров `rov0–7` вокруг квадрата застройки, стена `fence0–4` — когда построен Забор, курсор-рука на выбранной клетке,
стройка — столбик из 10 зелёных квадратиков; в мире — стрелки перехода по краям и инфо-окно клетки
(X/Y, замок, игрок, альянс, рейтинг). Интерфейс — дерево, цепи и уголки, полоса с часами и сообщениями, как в клиенте.

### Интерфейс как в Android-клиенте «Третий Мир 3D»

Раскладка повторяет 3D-клиент: сверху — конверты «Сообщения» и «Отчёты»; справа — выдвижная панель локаций
(Замок, Земли, Мир, Мои замки, Ресурсы); снизу — «Меню», строка чата с часами, шестерёнка настроек.
«Меню» открывает полосу из 7 кнопок (Кабинет, Локации, Альянс, Почта, Игры, Инфо, Рейтинг) и кожаное окно-список;
окна — пергамент с красными лентами, внизу ◀ (назад) и ✕ (закрыть). Стили окон — из APK клиента (`web/gfx3d`).

Работают: Профиль (как в оригинале: информация, репутация, Зал Славы, звание, альянс, плитки действий, замки),
Советник, Уведомления/Отчёты/События, Репутация (раз в сутки одному игроку), Земляки, Мои друзья, Поиск друзей,
Блокнот, Почта, общий Чат, Справка, Рейтинги (Зал Славы, Игрок, Замок, Альянс, Авторитет).
Пока заглушки: Казна, Премиум, Фотоальбомы, ЗАГС, Мои файлы, Подарки, Авторитет города, Биржа Замков,
Форум, Блог, Приватность, Игры, Знаменитость, Семейные пары, Империи.

Скриншоты каждого шага — `docs/img/ui3d/`.

### Боевые отчёты и захват замков

Отчёт о бое (Меню → Почта → Отчеты, или конверт «Отчёты» наверху): результат (ПОБЕДА / ПОРАЖЕНИЕ), сила атаки и обороны,
по каждой стороне — таблица юнитов «было / погибло / осталось» с картинками, генерал (пал ли в бою), Забор, добыча,
разрушения от таранов и катапульт, изменение лояльности. Защитник получает свой отчёт («Оборона»).

**Захват**: у каждого замка есть лояльность 0–100 (видна в Военном штабе), восстанавливается сама (быстрее с Храмом).
Каждый выживший Бунтарь в победной атаке снижает её на 20–30; при 0 замок переходит к нападающему. Захватывать можно
Заброшенные замки на карте (руины — на их месте появляется новый замок) и не-столичные замки игроков; столицу — нельзя.
Замков у игрока может быть несколько: «Мои замки» — список и переход между ними; рейтинг игрока — сумма его замков.
Админ-панель: «Прокачать игрока» — для проверки боёв. Скриншоты — `docs/img/reports/`.

### Армия, функции зданий, админ

**Админ**: логин `admin`, пароль `admin` (сменить — `ADMIN_PASS=... npm start`). Замок на полной прокачке: все здания
и земли на максимуме, склады полные, по 1000 каждого боевого юнита, генерал 20 ур., науки 20, артефакты.
В «Ещё → Админ-панель»: ресурсы до максимума, «завершить всё сейчас» (стройки, тренировка, наука, марши), +100 войск,
повторная полная прокачка.

| Здание | Функция в окне здания |
|---|---|
| Казарма / Конюшня / Академия магов / Мастерская / Портал / Таверна / Центр шпионажа | тренировка юнитов своей расы (оригинальные имена и картинки), очередь с прогрессом |
| Военный штаб | генерал (уровень, опыт, воскрешение), войска в замке, отправка армий, армии в пути, входящие атаки, отчёты |
| Рынок, Торговая палата | обмен ресурсов по курсу, торговцы везут ресурсы в другой замок |
| Посольство | альянсы: вступить по тегу, создать (с 3 ур.), выйти |
| Университет, Дом мудрецов | 4 науки (Экономика, Инженерия, Физика, Военное дело), мудрецы ускоряют |
| Храм | религия: Свет (защита), Природа (добыча), Война (атака) |
| Экспедиция, Лагерь археологов | археологи в руины → артефакты |
| Башня артефактов, Сокровищница | активация и хранение артефактов |
| Забор, Кузнец, Школа магии, Каменотес, Тайник, Караульная башня, Пивоварня, Лавка алхимиков | бонусы к бою, защите, тренировке, контрразведке, укрытие ресурсов |

Миссии (карта мира → объект): **атака**, **набег**, **разведка**, **экспедиция**, **торговля**. Цели — замки игроков и
NPC-лагеря (Дикари, Лесорубы, Рудник троллей, Заброшенный замок) с охраной и запасом добычи. Бой по формулам
GDD §9: пехота/кавалерия/магия, Забор, генерал, потери, грабёж с учётом Тайника, тараны ломают Забор, катапульты —
здания. Защита новичка — на игроков с рейтингом ниже 100 нападать нельзя. Отчёты приходят обеим сторонам.

Скриншоты: `docs/img/ui3d/` (интерфейс), `docs/img/reports/` (бои и отчёты), `docs/img/castles/` (захват и замки).
