- **Не править сразу, а сначала дать отчёт**, если изменение большое или неясное. По ясной команде — делать. Мелкие правки — сразу.

## Порядок после каждого изменения кода

1. `cd server && npm test` — 5 наборов: royal, web-smoke, net-guard, fuzz, sim. Все должны пройти.
2. `sh tools/pack.sh` — собирает `dist/game.zip`.
3. Коммит (понятное сообщение по-русски) и `git push -u origin claude/third-world-kings-war-analysis-lodxja`.
4. Скрины изменённых окон (демо-сервер, см. ниже), показать хозяину.
5. Дать версию (её печатает `pack.sh`) и шаги обновления сервера:
   1. Репозиторий на GitHub — сделать **Public**.
   2. `ssh root@<IP сервера>`
   3. `war-update https://raw.githubusercontent.com/Darkdini/vs/<ПОЛНЫЙ SHA коммита>/dist/game.zip && rm -rf /opt/war/game.old && echo "старая версия удалена"`
   4. `exit`
   5. Репозиторий — снова **Private**.
6. Если уместно — текст новости для игроков: заголовок до 80 символов, текст до 4000, без знаков `<` и `>`.

## Запреты и безопасность

- Никогда не класть в репозиторий логин и пароль админа, токены ботов, ключи. Не просить их в чате.
- Ключ Cloudflare Worker в коде остаётся заглушкой `ВПИШИТЕ_СВОЙ_КЛЮЧ`.
- Пароли — только хэшами. Никакой команды «сделать админом».
- Задания и боссы не дают золото (монеты) и премиум.
- Никаких настоящих товарных знаков в игре.
- Админ в игре невидим онлайн.
- Не коммитить лишние файлы (черновики, скрины, базы).
- Force-push — только по прямой команде хозяина.
- Git — без разрушительных команд: лучше `git stash`, чем удалить. В `stash@{0}` лежит «резервные коды (отменено пользователем)» — не трогать без команды.

## Ловушка, на которой уже обжигались

В этом коде много **длинных строк, где после кода идёт комментарий `//`**. Если вставить что-то в середину такой строки с `// пояснением`, всё, что было в строке дальше, превращается в комментарий. Так однажды пропали «МАСТЕРА» в меню, а бан аккаунта сам себя снимал. Пояснения посреди строки — только `/* так */`, а `//` — только в конце строки или отдельной строкой.

## Демо-сервер для скринов

```
cd server && DB=<путь к копии базы>.json WEB_PORT=8099 NO_CAPTCHA=1 NO_BACKUP=1 ADMIN_PASS=<любой тестовый> node src/index.js
```

Скрины — Playwright (Chromium), окно телефона Pixel 7. Первая загрузка графики после изменений бывает долгой — если не успело, повторить.
После скринов **обязательно остановить** сервер: `P=$(lsof -tiTCP:8099 -sTCP:LISTEN); [ -n "$P" ] && kill $P`.
