# Тестовый сервер для оригинального клиента «Третий Мир»

Node.js ≥ 16, **без зависимостей** — запускается в Termux как есть.

```bash
npm test     # смоук-тест протокола (поднимает сервер на случайном порту)
npm start    # 0.0.0.0:2500; SPEED=100 DEBUG=1 npm start — быстрый мир + дамп пакетов
```

| Файл | Что внутри |
|---|---|
| `src/protocol.js` | FLAP/SNAC/TLV, cp1251 как в клиенте |
| `src/ui.js` | конструктор окон (SNAC 12): текст, ссылки, поля, кнопки, сообщения, бегущая строка |
| `src/catalog.js` | здания и юниты с ID/названиями из клиента + тестовый баланс |
| `src/game.js` | аккаунты, замки, рельеф земель, ленивый расчёт ресурсов, очередь строек, JSON-хранилище |
| `src/handlers.js` | обработчики всех известных SNAC |
| `assets/images/` | картинки, которые сервер отдаёт клиенту по запросу (`<id>.png`) |
| `test/smoke.js` | повторяет байты настоящего клиента: регистрация → вход → стройка → карта → меню → почта |

Протокол: [`docs/04-protocol.md`](../docs/04-protocol.md). Запуск с телефоном: [`docs/05-local-testing.md`](../docs/05-local-testing.md).
