# Android 3D-клиент для локального теста

`tw3d_local.apk` — оригинальный клиент «Третий Мир: Война Королей 3D» 2.0.112, перенастроенный
на наш сервер `socket://127.0.0.1:5005` (Termux на том же телефоне) и переподписанный тестовым ключом
(собран `tools/repack_apk.py`).

> Файл содержит клиент Fenix-Soft. Держите репозиторий **приватным**, пока этот файл в нём лежит.

Установка:
1. Удалите оригинальную игру (подпись другая, поверх не встанет).
2. Скачайте `tw3d_local.apk` на телефон и установите (разрешите установку из неизвестных источников).
3. В Termux: `cd ~/vs/server && DEBUG=1 npm start`, затем запустите игру.

Если сервер на другом устройстве — пересоберите APK со своим адресом:
`python tools/repack_apk.py оригинал.apk tw3d_local.apk --host 192.168.x.x`
(тогда перед установкой снова удалите предыдущую версию — ключ подписи будет другой).
