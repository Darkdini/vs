## Тестовый сервер (первые шаги)

[`server/`](server) — сервер на Node.js без зависимостей, говорящий на протоколе оригинального клиента.
Уже работают: регистрация и вход, Замок/Земли/Мир, стройка и улучшение зданий с таймерами, ресурсы,
Кабинет, Рейтинг, почта между игроками, Bug-репорты. Проверено запуском **настоящего клиента** в эмуляторе.

```bash
cd server && npm test && npm start                                         # сервер на :2500
python3 tools/patch_client.py original.jar tw_local.jar --host 127.0.0.1   # J2ME-клиент → наш сервер
python3 tools/repack_apk.py original3d.apk tw3d_local.apk --host 127.0.0.1  # Android 3D-клиент → наш сервер (порт 5005)
```

## Данные баланса

- [`data/buildings.json`](data/buildings.json) — 32 здания: слой, макс. уровень, стоимость, рост, время, требования, эффекты.
- [`data/units.json`](data/units.json) — 64 юнита (4 расы × 16 ролей): атака, магия, защита, скорость, груз, содержание, стоимость, время, здание, требования.

Юниты генерируются из шаблона ролей и модификаторов рас; таблицы в GDD пересобираются из JSON:

```bash
python3 tools/gen_units.py      # data/units.json
python3 tools/render_docs.py    # таблицы в docs/02-game-design.md
```

> Точные числа оригинала (стоимость каждого уровня, параметры юнитов) в открытых
> источниках недоступны. Цифры в `data/` — наш собственный баланс, построенный по
> структуре оригинала. Чек-лист, что снять вручную из игры, — в `docs/01-research.md`, §9.
