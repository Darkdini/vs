# Война Королей — браузерная MMO-стратегия

Проект браузерной клиент-серверной стратегии по мотивам игры
**«Третий Мир: Война Королей»** (Fenix-Soft, 2009).

## Документация

| Документ | Содержание |
|---|---|
| [docs/01-research.md](docs/01-research.md) | Что известно об оригинале: расы, ресурсы, 3 слоя, здания, юниты, системы — с источниками и пометкой «подтверждено / догадка» |
| [docs/02-game-design.md](docs/02-game-design.md) | Полный геймдизайн нашей игры: все здания по слоям и требования, юниты 4 рас со стоимостью и временем, формулы боя, лояльность, торговля, альянсы/империи, профиль, рейтинги, премиум, объём MVP |
| [docs/03-architecture.md](docs/03-architecture.md) | Архитектура клиент-сервер: стек, модель времени, схема БД, API, WebSocket, анти-чит, план спринтов |

## Данные баланса

- [`data/buildings.json`](data/buildings.json) — 32 здания: слой, макс. уровень, стоимость, рост, время, требования, эффекты.
- [`data/units.json`](data/units.json) — 64 юнита (4 расы × 16 ролей): атака, магия, защита, скорость, груз, содержание, стоимость, время, здание, требования.

Юниты генерируются из шаблона ролей и модификаторов рас; таблицы в GDD пересобираются из JSON:

```bash
python3 tools/gen_units.py      # data/units.json
python3 tools/render_docs.py    # таблицы в docs/02-game-design.md
```

> Точные числа оригинала (стоимость каждого уровня, параметры юнитов) в открытых
> источниках недоступны. Цифры в `data/` — наш собственный баланс, построенный по
> структуре оригинала. Чек-лист, что снять вручную из игры, — в `docs/01-research.md`, §9.
