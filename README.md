# Война Королей — браузерная стратегия для Android

Клиент-серверная браузерная игра по мотивам «Третий Мир: Война Королей». Расы: Люди, Эльфы, Гномы, Орки. Мир рассчитан на ~5 000 игроков.
Играется в браузере телефона (Chrome), сервер — Node.js без зависимостей (запускается в Termux).

## Запуск на телефоне (Termux)

```bash
pkg install nodejs-lts            # один раз
termux-setup-storage              # один раз — доступ к «Загрузкам»
cd ~ && rm -rf vs && unzip -q ~/storage/downloads/vs-*.zip && mv vs-* vs
cd ~/vs/server && npm start
```

Открыть в Chrome: **http://localhost:8080**. Меню Chrome → «Добавить на главный экран» — игра во весь экран.

## Администратор

- **Логин:** `admin`
- **Пароль:** `admin` (другой пароль: `ADMIN_PASS=мойпароль npm start`)

У админа **20 замков на полной прокачке** (по 2300 рейтинга, всего 46 000), 1 000 000 золота, все войска, генерал 20 ур.

**Админ-панель:** Меню → Кабинет → **Админ-панель** (первый пункт). Команды действуют на вас или на игрока из поля «Игрок»,
по активному замку или по всем замкам:

| Раздел | Команды |
|---|---|
| Прокачка | полная прокачка, завершить всё сейчас (стройки, тренировка, наука, марши), науки 20 ур., + N полных замков |
| Ресурсы и золото | склады до максимума, ± ресурсы, ± золото |
| Армия | ± войска (все юниты или выбранный), генерал нужного уровня, 5 легендарных артефактов, убрать войска, лояльность замка |
| Игроки | список всех игроков (рейтинг, замки, золото, онлайн, бан); карточка игрока: замки и переход на карту, блокировка, сделать админом, удалить, ± репутация, новый пароль, переименовать и перенести замок |
| Связь и мир | письмо всем игрокам, объявление в чат, заселить мир ботами (проверка нагрузки), восстановить лагеря и руины, очистить отчёты, сообщения об ошибках |

## Настройки сервера

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `WEB_PORT` | 8080 | порт |
| `SPEED` | 10 | скорость мира (время строек, тренировки и походов делится; добыча ресурсов — как в оригинале) |
| `RES_SPEED` | 1 | множитель добычи ресурсов (для тестов) |
| `ADMIN_PASS` | admin | пароль администратора |
| `ADMIN_CASTLES` | 20 | сколько полных замков у админа |
| `WORLD_SIZE` | 1000 | размер карты мира (клеток по стороне), рассчитан на ~5 000 игроков |
| `SAVE_MS` | 10000 | как часто сохранять базу, мс (и всегда при остановке) |
| `DB` | `server/data/db.json` | файл базы; удалить — начать мир заново |

Проверка: `cd server && npm test`. Подробнее — [docs/05-local-testing.md](docs/05-local-testing.md).

## Структура

| Путь | Что там |
|---|---|
| `server/src/` | игра: `game.js` (замки, ресурсы, стройки), `army.js` (войска, генерал, бои, захват, функции зданий, админ), `social.js` (профиль, друзья, чат, Зал Славы), `catalog.js` (здания и баланс), `web.js` (HTTP + WebSocket) |
| `web/` | клиент: `app.js` (карта, окна зданий), `mil.js` (армия, отчёты), `ui3d.js` (меню, профиль, чат), `gfx/`, `gfx3d/` — графика |
| `data/` | баланс юнитов и зданий из дизайн-документа |
| `docs/` | разбор оригинальной игры, геймдизайн, запуск и скриншоты |
